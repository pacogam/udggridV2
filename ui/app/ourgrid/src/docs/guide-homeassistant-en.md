## Introduction

Connect Home Assistant and respond to challenges automatically. You'll receive all the information your system needs to meet the power target.

## Connect to Home Assistant

### Requirements

- A [GitHub account](https://github.com) is required to set up the Home Assistant Community Store.

### 1. Install HACS

1. Install the [Home Assistant Community Store](https://www.hacs.xyz/docs/use/download/download/) by following the installation guide on their website.
2. Set up the [HACS integration](https://www.hacs.xyz/docs/use/configuration/basic/) to allow community integrations to be installed.

### 2. Download the OurGrid integration

1. To open HACS, select the HACS icon in the Home Assistant left sidebar.
2. Search for **"OurGrid"** and download the integration. Restart Home Assistant.
3. On the same page, follow the configuration instructions using the credentials shown above this guide.

### 3. You're all set!
